## RÈGLE ANTI-LOOK-AHEAD — MÉTHODE UNIQUE OBLIGATOIRE

Les signaux sont calculés sur Close[t] mais exécutés sur Open[t+1].

MÉTHODE CANONIQUE (la seule autorisée) :
- price = df['Open'] — prix d'exécution, SANS shift
- entries = entries.shift(1) — décaler les signaux d'entrée de +1
- exits = exits.shift(1) — décaler les signaux de sortie de +1
- NE JAMAIS passer close= dans from_signals
- NE JAMAIS utiliser df['Open'].shift(-1) — cette syntaxe est INTERDITE

Appel correct complet :
vbt.Portfolio.from_signals(
    price=df['Open'],
    entries=entries.shift(1),
    exits=exits.shift(1),
    fees=0.001,
    slippage=0.001,
    init_cash=100000
)

Logique : le signal est émis à la clôture du jour t (Close[t]), donc l'ordre ne peut être exécuté qu'à l'ouverture du jour t+1. Le shift(1) sur les signaux retarde leur application d'une barre, et price=df['Open'] exécute au prix d'ouverture de cette barre.

Toute spec qui utilise close=, df['Open'].shift(-1), ou oublie le shift(1) sur les signaux sera rejetée par le Critique comme BLOQUANT.
